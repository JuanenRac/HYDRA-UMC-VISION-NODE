## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a vision-based safety system, a security flaw can lead to physical damage. If you discover a vulnerability affecting the **Hailo-8 inference engine**, **safety zone triggers**, or **gRPC communication**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows bypassing safety limits, spoofing detections, or crashing the vision node.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
